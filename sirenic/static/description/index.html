Ce qui sort de votre base, et ce qui n'en sort pas

Ce module appelle un service externe, l'API Sirenic (api.sirenic.eu). Sont transmis : l'identifiant de l'entreprise que vous vérifiez, et rien d'autre. SIREN, SIRET, numéro de TVA ou identifiant de registre national. Plus l'IBAN, si vous demandez son contrôle.

Ne sortent jamais : les noms de vos contacts, leurs adresses, leurs courriels, vos factures, vos montants, vos conditions commerciales. Aucun appel n'est émis tant que vous n'avez pas donné votre accord dans Paramètres, section Sirenic.

Gratuit, avec votre propre clé

Le module ne coûte rien et ne demande aucune clé d'activation. Les appels à l'API sont facturés à l'unité par Sirenic, à partir de 0,002 $, avec la clé que vous créez sur api.sirenic.eu. Vous voyez le prix avant de cliquer.

Ce que ce module ne fait pas

Le score de risque n'est pas une notation de crédit. C'est un indicateur d'aide à la décision, non contractuel, bâti sur les comptes déposés. Quand ces comptes datent de plus de dix-huit mois, le rapport le dit : un chiffre ne doit pas paraître plus sûr qu'il ne l'est.

L'identifiant national n'est déduit du numéro de TVA que pour la France, la Belgique et la Pologne, où la correspondance est documentée. Ailleurs, seul le contrôle VIES du numéro est possible, et le module l'écrit plutôt que de deviner un identifiant de registre. Une donnée plausible et fausse coûte plus cher qu'une donnée absente.

Une correspondance de criblage signale un homonyme à lever sur les listes officielles. Elle n'établit pas qu'une personne ou une entreprise est sanctionnée, et le rapport le précise.

Où il s'installe

Odoo.sh et on-premise. Odoo Online n'accepte aucun module tiers, celui-ci comme les autres. Si vous êtes sur Odoo Online, notre application Make atteint Odoo par son API externe et fait le même travail.

Configuration : Paramètres, section Sirenic. Lisez ce qui est transmis, cochez le consentement, collez votre clé. Deux minutes.
